# SJTU-ViT MLD: manuscript figure code

Analysis and plotting code accompanying **A monthly 1 degree global ocean
mixed layer depth dataset for 1982-2023 developed with SJTU-ViT**.

This repository currently contains the analysis and plotting notebooks for
main-text Figures 2-9 and Supplement Figures S1-S7. It is not the full SJTU-ViT
training or inference implementation. Data preprocessing, model training,
hyperparameter optimization, inference, and uncertainty estimation are outside
the scope of this initial code collection and may be added in later versions.

## Setup

1. Create an isolated Python environment and install the dependencies:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

2. Create a local configuration and edit its paths:

   ```bash
   cp config.example.json config.json
   ```

   Relative paths are resolved from the repository root, not from the notebook
   directory. `config.json` is ignored by Git. An alternative configuration file
   can be selected with the `SJTU_VIT_PLOT_CONFIG` environment variable.

3. Obtain the required data separately. The final public MLD product alone is
   **not sufficient** for all figures: several notebooks require paired
   predictions and WOD-derived reference values, the original train/validation
   subsets, climatologies, station records, or profile counts. Do not substitute
   the single-variable public product for the paired analysis files without
   adapting and verifying the workflow. See
   [data requirements](docs/DATA_REQUIREMENTS.md).

4. Provide legally obtained `Times New Roman.ttf` and `Times New Roman Bold.ttf`
   files in the configured `font_dir`. The original font checks are retained;
   these proprietary font files are not distributed here. Cartopy may download
   Natural Earth map data on first use, so an initial network connection or a
   populated Cartopy cache is also needed.

5. Start JupyterLab from the repository root:

   ```bash
   jupyter lab
   ```

   Select the installed Python kernel and run a notebook from its first cell,
   in order. Restart the kernel when switching notebooks. For Supplement S5,
   run the HOT preparation in `figure4.ipynb` first, or supply the corresponding
   `HOT_MLD_clean.nc` in the configured work directory. Supplement S6-S7 require
   the profile-count file generated by `s1figure.ipynb`, or an equivalent
   precomputed input. S1's profile-count calculation can be expensive.

All figure images are written to `output_dir`; generated intermediate files are
written to `work_dir`. These directories and all input data are excluded from
the code release. No notebook is automatically executed at download
or import time by the packaging checks.

## Verification and status

```bash
python tools/validate_repository.py
```

The repository has been checked for notebook JSON integrity, Python syntax,
cleared outputs, path configuration coverage, and common credential patterns.
The numerical analyses have **not** been rerun in a clean environment with all
required data. `requirements.txt` is not an exact environment lockfile. A
successful static check does not establish numerical or visual reproduction
of the published figures.

## Repository and associated data

Code repository: https://github.com/haolin111/SJTU-ViT-MLD.

The associated SJTU-ViT MLD data product (version 1.0) is archived at
https://doi.org/10.5281/zenodo.23463931 under the Creative Commons Attribution
4.0 International (CC BY 4.0) licence. This DOI identifies the data product,
not the plotting software. No separate software DOI has been assigned.
Record the exact Git commit used when citing or reusing the code.

No trained weights, original observations, third-party data, font files, or
manuscript documents are included. Required figure inputs and their
availability are described in [data requirements](docs/DATA_REQUIREMENTS.md).
